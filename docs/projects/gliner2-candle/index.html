Extraction without the detour.

GLiNER2 unifies named entity recognition, text classification, structured data extraction, and relation extraction through a schema-driven interface. GLiNER2.5 advances the GLiNER family with a newer boundary-oriented architecture. This implementation brings both lines into Rust/Candle, where local execution, portable binaries, and tight control over inference matter.

New, and unusually capable

This is a new release, but not a narrow port. It is a systems-level implementation of two recent GLiNER generations: the multi-task GLiNER2 model and the GLiNER2.5 boundary model. That makes it a useful foundation for agent memory, document understanding, retrieval pipelines, and other workloads where structured signals should be extracted locally.

  • GLiNER2 schema-based multi-task extraction
  • GLiNER2.5 boundary-architecture inference
  • Entity recognition and relation extraction
  • Classification and structured data extraction
  • Rust/Candle execution for local inference

Upstream references: GLiNER2 repository, GLiNER2 paper, and the GLiNER repository.
