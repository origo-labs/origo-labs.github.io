Search is an agent primitive.

Agents do not need more code in their context. They need the right code, with enough structure to act on it. Semble-rs indexes local repositories and Git URLs into a persistent, searchable corpus.

Hybrid by design

Semantic retrieval handles intent. BM25 catches exact identifiers. Tree-sitter keeps chunks aligned with code structure. Together, they make search useful for concepts and symbols alike.

  • Native binary with no Python runtime
  • CLI and self-describing MCP server
  • Parallel indexing with persistent cache
  • Multiple language grammars with line-based fallback
