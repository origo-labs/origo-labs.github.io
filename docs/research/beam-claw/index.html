Code is an effect. Make it reversible.

BEAM-Claw mechanizes three composability axes on stock OTP primitives: temporal composability through revertible effects, spatial composability through monitored capability registries, and evidentiary composability through a hash-chained ledger.

The central invariant

Every mutation is born with its inverse. When an agent acquires a capability, it also acquires the operation that decommissions it. A failed turn can unwind the capability, its registrations, and its code.

Validated end to end

The included Experiment 1 is complete. In three phases, an LLM first encountered a capability gap, then authored and hot-loaded an Erlang memory tool, and finally triggered a failure that correctly unwound the evolved capability. The repository reports 24 passing tests, a stateful PropEr suite, clean xref/dialyzer checks, and a hash-chain ledger verified at startup.

  • Self-authored Erlang modules compiled and hot-loaded mid-turn
  • Dynamic tool schemas refreshed before each model request
  • Supervised fibers unwind pending effects in LIFO order
  • Filesystem access confined to a workspace with atomic writes
  • All model exchanges recorded in tamper-evident JSONL

This page summarizes the repository’s public whitepaper, specification, and experiment report. It is research content, not a claim that the runtime is production-ready for arbitrary autonomous code execution.
