More tools do not automatically mean more capability.

When an agent receives a large catalogue of tools and schemas up front, the context becomes a search space the model must navigate before it can do the work. A compact capability index changes that interaction.

From phone book to menu

Warmplane is built around this idea: expose a short, high-signal surface first, then reveal detailed schemas only when the model has identified the capability it needs.
